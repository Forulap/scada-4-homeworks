Техническое задание
Создайте интерфейс для мониторинга и управления системой подачи жидкости с подающим насосом, тремя отборными трубопроводами и емкостями.

Задачи
1.	Постройте графическую схему технологического процесса.
2.	Реализуйте управление насосом и вентилями.
3.	Отобразите текущие параметры давления и расхода на подающем трубопроводе.
4.	Рассчитайте параметры на отборных трубопроводах с использованием скриптов.
5.	Визуализируйте наполнение емкостей.

Описание технологического процесса

Система включает:

●	подающий насос — обеспечивает циркуляцию жидкости;

●	три отборных трубопровода — каждый оснащен вентилем для регулирования потока;

●	емкости — заполняются жидкостью из отборных трубопроводов.

Параметры:
●	давление и расход на подающем трубопроводе задаются явно;

●	(например, через тэги с фиксированными значениями или ручной ввод);

●	на отборных трубопроводах давление и расход рассчитываются скриптом на основе:

●	положения вентилей (процент открытия),

●	общего давления/расхода на входе,

●	упрощенных формул (например, $Q{отбор} = Q{общ} *(открытие вентиля)/(100) ).

●	скорость наполнения уровня в емкостях рассчитывается как пропорциональный коэффициент от расхода на каждом трубопроводе.  

Требования к функционалу

Управление:

●	включение/выключение насоса кнопкой;

●	регулировка положения вентилей (0–100%) через элементы интерфейса.

Мониторинг:

●	отображение текущих значений давления и расхода на подающем трубопроводе;

●	отображение рассчитанных значений давления и расхода на каждом отборном трубопроводе.

●	индикация уровня заполнения емкостей (в процентах или объеме).

Расчеты:

●	скрипт для перераспределения давления и расхода между отборными трубопроводами.

Требования к графическому интерфейсу

Элементы:
●	технологическая схема с насосом, трубопроводами, вентилями и емкостями;

●	анимация состояний:

●	индикация включения насоса при работе,

●	движение уровня в емкостях;

●	индикаторы: цифровые дисплеи для давления, расхода, уровня;

●	формы для ручного ввода параметров (опционально);

●	цветовая индикация превышения давления в трубопроводах.
