# Домашнее задание к занятию «HMI. Человеко-машинный интерфейс»

### Цель задания

Понимание основных принципов работы HMI поможет корректно подбирать HMI-панели по заданным критериям проекта, а также проектировать интерфейсы экранов для управления производственным процессом.

В результате выполнения этого задания вы сможете:

* подбирать HMI-панели из стека наиболее применяемых брендов в современных системах автоматизации;
* спроектировать систему управления реальным процессом на базе HMI.

### Задание 1

**Задача 1**	

Вам, как инженеру научно-внедренческой фирмы, выдано техническое задание на проектирование системы управления производством. Один из пунктов проектирования — подбор и закупка HMI-панелей производителей SIEMENS, ALLEN BRADLEY, OMRON. Есть требования от заказчика: 

 - одна панель SIEMENS серии Comfort — основная панель управления технологическим процессом; диагональ экрана — минимум 14 дюймов, объём памяти — минимум 24 Мб;
 - один промышленный компьютер SIEMENS для доступа к базе данных предприятия; объём оперативной памяти — 2 Гб, объём жесткого диска — минимум 250 Гб, диагональ экрана — минимум 14 дюймов;
 - пять панелей SIEMENS серии Basic — локальные панели управления на постах; диагональ экрана 7 дюймов, наличие функциональных кнопок;
 - пять графических терминалов ALLEN BRADLEY серии PanelView5500 — управление постами, диагональ 10,4 дюймов, 1 Гб RAM;
 - одна панель OMRON любой серии на выбор студента — управление установкой; диагональ 10,4 дюймов, разрешение экрана — минимум 1024х768, объём программы — 30 Мб.

Подберите оборудование, соответствующее требованиям. Заказные номера внесите в [документ на закупку](https://docs.google.com/spreadsheets/d/1Ih_-mCGzfW3cF6gGTHU2iP1vPlzDokyZxKrSygQIYl4/edit?usp=sharing), предварительно сделав его копию себе на диск.

Общую инструкцию по пользованию сайтами основных постащиков оборудования HMI вы сможете найти по [ссылке](https://docs.google.com/presentation/d/1F4vQHjKqPY_StbscL3Xb_Y1u2nsXxXmnnMarEq8DFxw/edit?usp=sharing). 

**Задача 2 * (необязательная)**

Спроектируйте схему топологии сети подобранных панелей в любом удобном ПО, например, [Cisco Packet Tracer](https://www.netacad.com/ru/courses/packet-tracer) или MS Visio. Также добавьте в топологию сети 3 PLC-контроллера (SIEMENS, ALLEN BRADLEY, OMRON). Каждый из этих контроллеров связан с системой HMI по сети Ethernet / Profinet своей фирмы-производителя.

Результат выполнения задания — набор файлов:

 - документ на закупку, в котором нужно заполнить заказные номера и другую информацию для заказа;
 - схема топологии сети, выполненная в формате .vsd, .vsdx, .jpeg, .jpg, .png.

### Задание 2

Нужно спроектировать систему управления на базе HMI из списка вариантов:

 - система управления откачкой воды из приямка;
 - система управления паровым котлом.

Выберите один вариант системы, который вы хотели бы реализовать. 

Объём — 3–5 экранов HMI, включающих в себя:

- основной экран — основной вид и главные параметры системы, указанные в ТЗ;
- экран настроек системы управления — настройки указаны в ТЗ;
- список ошибок — отображение ошибок, указанных в ТЗ;
- дополнительно 1–2 экрана HMI могут быть спроектированы на усмотрение студента.

Технические задания можно найти по [этой ссылке](https://docs.google.com/document/d/1L1uxjRuVJC4v2dyChpJliah0JY6sr6H47sSHIdrdt5U/edit?usp=sharing).

Результат выполнения задания — проект, разработанный в программе «Конфигуратор СП300», соответствующий техническому заданию.
