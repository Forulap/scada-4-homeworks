# Домашнее задание к занятию «SCADA. Основы работы»

### Цель задания

Понимание базовых принципов построения SCADA-систем — основопологающие знания в области SCADA. Правильное построение и обеспечение защищённости SCADA — важный шаг создания надёжной и продолжительной системы автоматизации. 

В результате выполнения этого задания вы сможете:

* закрепить полученные знания по основам SCADA;
* получить практические навыки по построению SCADA-систем;
* освоить приципы построения SCADA-систем;
* научиться выявлять риски в работе SCADA-систем и способы их предотвращения*.

### Критерии оценки

Зачёт ставится, если выполненное задание соответствует критериям:

1. Для всех объектов управления присвоены органы управления: и у оборудования, и из диспетчерского поста.
2. Для всех органов управления указаны связи с оборудованием, для управления которым они предназначены.

5. Предложены меры по предотвращению всех выявленных рисков.
