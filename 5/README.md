# Домашнее задание к занятию «Сообщения, архивы, пользователи в MasterSCADA»

### Цель задания

Работа с журналом событий и архивом событий в MasterSCADA позволяет отслеживать и анализировать работу оборудования. Работа с настройками пользователей даёт возможность управлять их правами в MasterSCADA.

В результате выполнения задания вы сможете:

* выводить на экран сообщения о событиях, настраивать условия их вывода на экран;
* работать с архивом событий и экспортом архива;
* создавать пользователей и управлять их доступом.

### Задание 2

1. Создайте трёх пользователей:

 - самый главный диспетчер — пароль: bigboss;
 - главный диспетчер — пароль: almostbigboss;
 - диспетчер — без пароля.
 
2. Присвойте права доступа при помощи ролей:

 - самый главный диспетчер: полный доступ к системе;
 - главный диспетчер: полный доступ к управлению станцией 2, доступ к станции 1 — только просмотр без возможности управления;
 - диспетчер: доступ ко всем окнам только в режиме просмота без возможности управления.
