# Домашнее задание к занятию «WinCC»

### Цель задания

Simatic WinCC (Windows Control Center) — это система HMI, то есть программное обеспечение для создания человеко-машинного интерфейса.  WinCC — составная часть семейства систем автоматизации Simatic, производимых компанией Siemens AG. 

В результате выполнения этого задания вы сможете:

* создать проект WinCC;
* работать с окнами WinCC flexible;
* находить причины неисправностей при загрузке проекта WinCC;
* реализовывать способы интеграции проекта WinCC в Step7.
